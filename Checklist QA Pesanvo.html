Cara pakai (singkat)

  • Centang kotak kalau butir sudah dites dan hasilnya benar. Progres dihitung otomatis di bagian atas halaman.
  • Kalau menemukan masalah: klik tombol Bug di baris itu (baris jadi merah), lalu klik Catatan untuk menulis apa yang terjadi. Setelah itu klik Laporan bug di atas untuk menyalin semua bug.
  • Jangan lupa tes di HP asli (bukan cuma kecilkan jendela) dan di 2 bahasa (ID & EN), tema terang & gelap.
  • Penting: halaman ini tidak bisa menyimpan di browser. Kalau ditutup/di-refresh, centang hilang. Klik Simpan / muat progres untuk menyalin progres (teks), simpan di catatan, dan tempel lagi untuk melanjutkan.
  • Jangan pakai akun produksi asli untuk tes pembayaran. Pakai mode sandbox / nominal kecil.

P1 = penting sekali, tes duluan HP = cek di layar HP Admin = hanya admin

Dibuat dari audit kode Pesanvo (route, view, controller, config paket). Jika ada fitur baru, tambahkan butirnya di bagian data pada file ini.
